# Contributing to Atlas

The catalog is the core product. A good contribution makes a learner's next step easier and improves trust.

## A resource submission should include

- Stable name and canonical destination URL.
- Concise, original description and a specific `best_for` statement.
- One or more existing subject tags.
- Format, level and access; use an explicit unknown value instead of guessing.
- Source provenance and a review note.
- A note about licensing/access restrictions where relevant.

## Review checklist

1. Does the destination directly teach, explain, document, or support practice?
2. Is the URL canonical and not a duplicate of an existing destination?
3. Is the content relevant to the subject tags?
4. Are difficulty, access and format supported by the destination itself?
5. Is the verification state honest and timestamped?
6. Does the resource add something distinct to the catalog?

Do not add a rating, popularity estimate, “best” claim or AI score without a transparent method and source.
