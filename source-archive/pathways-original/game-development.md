# 🎮 Game Development Foundations

A flexible route from programming basics to a small playable project. Choose one engine first; you do not need to learn every engine at once.

## 1. Build the programming foundation

Review variables, functions, control flow, data structures and debugging. For browser games, start with JavaScript; for Python-based 2D work, explore Python and Pygame; for engine-based development, learn the language used by your chosen engine.

- [`CS50x — Introduction to Computer Science`](../subjects/computer-science/README.md#cs50x) — general programming and computer-science foundations.
- [Dani Krossing](../subjects/game-development/README.md#yt-game-dani-krossing) — Unity and C# starting point.
- [Clear Code](../subjects/game-development/README.md#yt-game-clear-code) — Python and Pygame projects.

## 2. Choose one engine

Pick an engine based on the kind of project you want to make. Read its official documentation alongside a guided tutorial.

- [Godot Engine Documentation](../subjects/game-development/README.md#game-godot-docs) and [GDQuest](../subjects/game-development/README.md#yt-game-gdquest) for Godot.
- [Unity Learn](../subjects/game-development/README.md#game-unity-learn) and [Brackeys](../subjects/game-development/README.md#yt-game-brackeys) for Unity.
- [Unreal Engine documentation](../subjects/game-development/README.md#game-unreal-graphics) and [Zenva](../subjects/game-development/README.md#yt-game-zenva) for Unreal Engine.

## 3. Build one small complete game

Start with a tiny scope: one mechanic, one level, a clear start and end, and a simple interface. Use a tutorial as a guide, then modify the result so that you understand the code and design choices.

- [HeartBeast](../subjects/game-development/README.md#yt-game-heartbeast) — 2D game systems and projects.
- [DaFluffyPotato](../subjects/game-development/README.md#yt-game-dafluffypotato) — Python/Pygame practice.
- [Mix and Jam](../subjects/game-development/README.md#yt-game-mix-and-jam) — studying short mechanic recreations.
- [`CS50’s Introduction to Game Development`](../subjects/game-development/README.md#game-cs50-games) — a university course with guided projects.

## 4. Explore graphics and game mathematics

After completing a simple game, explore vectors, transforms, interpolation, collision concepts and rendering.

- [Freya Holmér](../subjects/game-development/README.md#yt-game-freya-holmer) — visual mathematics for game development.
- [The Art of Code](../subjects/game-development/README.md#yt-game-the-art-of-code) — shaders and procedural graphics.
- [The Cherno](../subjects/game-development/README.md#yt-game-the-cherno) — C++, engine architecture and graphics programming.

## 5. Learn from the wider game-development community

Use conference talks and independent development diaries to understand design trade-offs, production planning and how teams build games.

- [Game Developers Conference (GDC)](../subjects/game-development/README.md#yt-game-gdc) — professional talks across game disciplines.
- [Jonas Tyroller](../subjects/game-development/README.md#yt-game-jonas-tyroller) — independent development process.
- [CodeParade](../subjects/game-development/README.md#yt-game-codeparade) — experimental, math-driven games.
