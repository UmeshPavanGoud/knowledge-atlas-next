# 🤖 Machine Learning Foundations

A prerequisite-aware route into machine learning, from mathematics and statistics to model implementation.

> Suggested order, not a mandatory syllabus. Adjust the depth to your prerequisites.

## 1. Prepare the mathematics

Review linear algebra, calculus, probability and statistics.

- [`math-mml-book`](../subjects/mathematics/README.md#math-mml-book) — catalog resource.
- [`data-openintro-statistics`](../subjects/data-science/README.md#data-openintro-statistics) — catalog resource.

## 2. Learn core ML methods

Use an introductory text, then progress to a rigorous university course.

- [`ai-statistical-learning`](../subjects/artificial-intelligence/README.md#ai-statistical-learning) — catalog resource.

- [`ai-fastai`](../subjects/artificial-intelligence/README.md#ai-fastai) — catalog resource.

## 4. Explore modern model families

Study transformer-based approaches and open model tooling.

- [`ai-hf-learn`](../subjects/artificial-intelligence/README.md#ai-hf-learn) — catalog resource.
